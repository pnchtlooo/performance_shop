# performance_shop
Финальное задание для курса по нагрузочному тестированию

1. Цель

Подтвердить или опровергнуть 3-кратный запас системы от нагрузки пикового часа.
Тест непрерывный, 2 часа, с проверкой показателей на уровнях 1x / 2x / 3x.
Запуск скрипта НТ jmeter -n -t performance_shop_test.jmx -l \results\run.jtl -e -o \html_report

В качестве тестовых данных использовались users.csv
Анализ результатов прогона выполнили с помощью скрипта analyze_results.py
